# 独立复用发现与修正

独立代理在不接触工程历史对话的上下文中，读取两个技能并解决传感器IQ与Overlay交付问题。原始输出存 reuse_case_result.md；其中时间、路径和脚本指纹指当次修正前版本，不能当作当前脚本指纹。夹具均按题面合成，不是板上或射频数据。

发现：HWH的FULLNAME带前导/，脚本只规范化XML名称，没有规范化命令参数。直接复制 /dsp/filter_0 会误报缺失。
修正：对用户 --require-ip 同样去掉前导/；保留缺项检查和hardware_validated=false。
复测：新增 test_pynq_accepts_copied_fullname 并运行25项回归；同时在保留的独立任务夹具上重新运行前导/命令，退出码0，详见 forward_retest.json。

可支持的效果：一项跨题目离线任务能够按技能生成可复算统计，并拒绝把stable、四点等幅和占位bit静态通过写成锁相、BER或所有板卡适配通过。仅此一次试用，不能证明任意任务或任意模型的成功率。

已知限制：元信息仍依赖提供者；如果sample不是导出流连续序号或inc来自不同观测点，应先修订输入契约，不以数值差异强行锁定硬件根因。
