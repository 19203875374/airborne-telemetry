# 输入数据契约与脚本局限

## IQ CSV

脚本要求 UTF-8 或 UTF-8-BOM 的逗号分隔 CSV，首行为唯一列名，默认列 i、q。额外列允许存在。用 --i、--q 明确映射不同列名，不自动猜测大小端、有符号数、仪器头或交替存储格式。

可选列：
- sample：此导出 IQ 流的连续样本序号；必须在所选记录中严格递增。空缺产生断段，频率统计不跨越断段。
- inc：按已解释为有符号的相位增量数值；使用 --inc-fs 明确累加器实际更新频率，不能默认为 IQ 导出采样率。
- mode 与 valid：显式指定列与目标值进行筛选；数值原样保留，筛选本身也记入输出。

Fs 是导出复样本率，单位 Hz。若 sample 是系统时钟周期索引且 valid 稀疏，需要先构造保留原始周期索引的等间隔有效流索引；不能直接假装连续。不同采样率或混合模式请分次调用。

PAPR = 10log10(max(I²+Q²)/mean(I²+Q²))。不剔除零样本或过渡段，不自动归一化。按任务先复制并明确筛选稳态区间，再计算；同时保存原始文件哈希与筛选规则。全零数据返回 null，不宣称 0 dB。

相邻相位差只在非零、索引相差1的样本对上计算，结果处于主值范围，不能自动解除超过 Nyquist 的混叠。它不独立证明载波恢复、相位连续性或调制标准符合性。输入为实 RF、交替 I/Q 单列或仪器私有 CSV 时先进行有记录的适配。

## 黄金参考比对

以行序逐项比较所选列，误差门限为 atol + rtol×abs(golden)。默认零容差。推荐把 sample 或符号编号一并选入列，防止遗漏对齐差异。脚本不搜索时延、不旋转相位、不补点、不自动选择有利片段。不直接处理复数文本或环绕相位；应显式转为可比较的 I/Q 或其他量。

参考数据必须来自独立数学模型、已确认输出或文档约束。把待测输出复制成 golden 只能演示工具接口，不能验证算法。内置 demo 是人工合成的脚本校验夹具，不是射频实测。

## 文件清单

record 只读取 --files 明确给定的根目录内文件；verify 检查内容与尺寸。拒绝绝对路径、上级跳转、逃逸软链接。新清单不覆盖已有清单。工具未解析 XPR/XCI、Tcl、IP 缓存、系数依赖，也不运行构建。依赖与构建须按案例模板另行检查。

## 运行环境

脚本依赖 Python 3.10+ 标准库，不要求 MATLAB、Vivado、PYNQ、联网或特定板卡。运行会读取本地数据；只有 release_manifest.py 的 record 会创建指定的新 JSON 文件。
