# 经验来源与验证分级

来源为随包提交的《机载遥测系统 全工程大模型协作与纠偏记录》。章节编号用于追溯，不把新编技能当成历史原话。源对话并未全部逐字找回。

| 经验 | 失败或观察 | 复用方法 | 已有证据 |
|---|---|---|---|
| L01 实现范围分层 | 第1至3项：需求与协议设想容易写成已实现功能 | 需求／计划／源码／仿真／板上／端到端分别记录 | 有日期的早期用户约束与后续范围修订 |
| L02 数据时钟先核对 | 第5项：inc=1434的频率量级与图中数值冲突 | 区分 IQ 样本率、累加器更新率、系统与 DDR 时钟，代入单位复算 | 恢复报告纠正16 MHz条件为约350.098 kHz；异常唯一根因未全部确认 |
| L03 验证层次匹配 | 第4、6项：tb_tx_top不能覆盖未实例化支路；SPI仿真不证明GHz输出 | 先定位顶层和观测点，再定义能支持的结论 | 历史顶层说明与特定条件下联合仿真反馈 |
| L04 测试激励先验证 | 第8至10项：零输入仍有残余RF，旧单音源并非严格纯复单音 | 零输入／复直流／偏移复单音分别设计反证，记录唯一改动 | 保存的25页调试摘录中有模型撤回与修订原文 |
| L05 多假设隔离 | 第11、12项：窄线原因和寄存器解释随测试变化 | 设计有区分力的实验，更新而非固守归因 | 前两项隔离测试反馈可查；最终根因与测试3原文不完整 |
| L06 数值追溯 | 第16、17项：面板PAPR固定数组、频谱批次与文件后缀混用 | 由已选择的真实数据重算，保存元信息与指纹 | 源码固定数组本次直接核实；历史恢复报告包含独立重算 |
| L07 失败状态保留 | 第15、18项：算法及stable/manual迭代后仍有失败反馈 | 文件名和文件存在不等于测试通过 | 历史失败反馈与多版脚本归档；不声称卡退已解决 |
| L08 版本优先于注释 | 第7、19项：旧65抽头注释、当前129项系数，旧接收与当前顶层混用 | 哈希、实际实例与配置核对；依赖单列 | 恢复报告有分支和字节比对，不确认当前烧录状态 |
| L09 协议主线须服从实际数据组织 | 第20、21项：误套CCSDS或将PSK分支视为完整网络协议 | 核对组帧/封装路径；新方案与实际PRBS原型分开 | 用户明确修订；方案实现证据仍不足 |

验证等级：H=有历史观察支持方法；S=本包脚本在合成夹具上已测试；B=在明确板卡与版本上复测。当前本包只声明 H 与脚本报告中列出的 S，不声明 B，也不保证模板在任意模型上稳定完成任务。

通用PYNQ分项由 L08 的版本一致性经验迁移，并参考官方PYNQ文档；属于本次新编静态预检，不是团队历史已完成的PYNQ系统。
