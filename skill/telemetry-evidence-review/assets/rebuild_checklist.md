# 陌生队伍接手工程的复现检查模板

1. 列工具版本、器件型号、顶层、时钟约束、必要IP版本与生成方式。
2. 列源码、系数、XCI、Tcl、初始化表、外部数据及其路径，检查相对路径。
3. 用 release_manifest.py 记录选定文件；对清单遗漏的依赖单独检查。
4. 在干净目录按实际构建命令重建，保存全部日志、退出码、资源及时序报告。
5. 将产物哈希与源快照、构建日志相互关联。字节不同不直接等于功能不同。
6. 仿真使用独立golden与公开容差；不能把待测输出复制成黄金参考。
7. 板上验证由持有板卡的队伍执行；记录烧录标识、供电、接线、仪器与测量设置。
8. 未执行的检查写未执行。哈希校验成功不等于干净环境重建或上板通过。
